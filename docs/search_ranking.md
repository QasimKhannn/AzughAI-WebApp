# Search and Ranking Pipeline

## Overview

One of the main features of Azugh AI is to suggest appropriate products to users based on multiple factors including:
- User search query
- User profile information
- Aesthetic preferences

The pipeline outputs a ranked list of products with length equal to the number of products the user requested. The primary objective is to propose products with high purchase probability, thereby reducing the time users spend browsing through products to find suitable matches.

## Input Variables

The pipeline accepts the following inputs:

- **User search query** ($\mathbf{q} \in \mathbb{R}^{728}$): A vector embedding of dimension 728 representing the search prompt.
- **Hard encoded keys** ($\mathbf{k}$): Categorical filters such as product number, product type, gender, etc.
- **User details** ($\mathbf{u} \in \mathbb{R}^{728}$): A vector embedding of dimension 728 containing user information collected during onboarding.
- **User liked products** ($\mathbf{p} \in \mathbb{R}^{728}$): A vector of dimension 728 representing the linear combination of products previously liked or purchased by the user.
- **Aesthetic details** ($\mathbf{A} \in \mathbb{R}^{728 \times n}$): A matrix of dimension $728 \times n$, where the first $n-1$ columns are vector embeddings of aesthetics preferred by the user, and the $n^{th}$ column is an embedding of the aesthetic description generated by an LLM for a travel destination or occasion.

## Search Pipeline Methodology

1. **Filtering Stage**:
   Filter the vector database using the hard-encoded keys provided in $\mathbf{k}$.
   
   $V_f = \text{Filter}(V_{DB}, \mathbf{k})$
   
   where $V_f$ represents the filtered vector space of products.

2. **KNN Similarity Search**:
   Perform k-nearest neighbors search using cosine similarity with a combined vector $\mathbf{v_{emb}} \in \mathbb{R}^{728}$:
   
   $\mathbf{v_{emb}} = \alpha\mathbf{q} + \beta\mathbf{u} + \gamma\mathbf{p} + \sum_{i=1}^{n} \delta_i \mathbf{A}_i$
   
   where $\alpha, \beta, \gamma, \delta_i$ are weighting coefficients, and $\mathbf{A}_i$ represents the $i^{th}$ column of matrix $\mathbf{A}$.
   
   The output $V_{emb}$ consists of the top $N$ product vectors with highest similarity to $\mathbf{v_{emb}}$.

3. **Ranking Model**:
   Apply a Convolutional Neural Network (CNN) ranking model that processes a similarity matrix $\mathbf{S} \in \mathbb{R}^{N \times (3+n)}$:
   
   $\mathbf{S}_{i,1} = \text{similarity}(V_{emb_i}, \mathbf{q})$
   
   $\mathbf{S}_{i,2} = \text{similarity}(V_{emb_i}, \mathbf{u})$
   
   $\mathbf{S}_{i,3} = \text{similarity}(V_{emb_i}, \mathbf{p})$
   
   $\mathbf{S}_{i,j+3} = \text{similarity}(V_{emb_i}, \mathbf{A}_j)$ for $j \in \{1,2,...,n\}$
   
   The output is a normalized relevance score vector $\mathbf{r} \in \mathbb{R}^{N}$.

4. **Product Ranking**:
   Sort products based on their relevance scores in descending order:
   
   $\text{RankedProducts} = \text{SortDescending}(V_{emb}, \mathbf{r})$

5. **Result Selection**:
   Extract the top $r$ products, where $r$ is the number of products requested:
   
   $\text{Results} = \text{RankedProducts}[1:r]$

6. **Retrieval**:
   Fetch the complete product information for the selected products from the relational database.
